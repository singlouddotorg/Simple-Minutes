Simple Minutes

← Back to Simple Minutes

A phone-sized logger for a regular singing: pick a book, tap the page number of each song as it's called, download or copy the file when you're done. This page covers the whole thing, plus a few features worth knowing about along the way.

Quick Start

  1. Open Simple Minutes on your phone, ideally before the singing starts.
  2. Fill in the event, date, and location, and pick a songbook.
  3. Tap the page number of each song as it's called, then Done.
  4. Tap Break for a recess.
  5. When the singing ends, Download CSV or Copy CSV.
  6. Open that file in Simple Compile or the full Minutes app to turn it into real, readable minutes to share.

Setting Up

  • Fill in Event, Date, Location, and Number Present to get started. None of it is locked in — tap Edit setup at any point during the singing to fix a typo, add the location if it wasn't decided yet, update the head count, or change which books are selected, then pick right back up logging songs. Nothing already logged is affected by an edit here.
  • Pick a songbook from the list. If it isn't in the visible list, use the search field — Simple Minutes knows a large and growing number of tunebooks (see "Where the songbook data comes from," below), most of which stay tucked behind search since any one singing only ever needs a couple of them.
  • Optional: set expected break times. The clock turns red and pulses starting five minutes before each one and for two minutes after, so a break doesn't slip past unnoticed while you're heads-down logging songs.
  • Optional: tick keep the screen awake, so the phone doesn't lock mid-singing and force you to unlock it one-handed between songs.

Logging Songs

  • Tap the number of each song's page on the keypad, then Done. The current time sits right beside the number you're typing, at the same size, so you never have to leave the keypad just to check it.
  • Some pages carry two songs, one above the other — the keypad prompts T or B for those, rather than guessing which one was meant.
  • Tapping a page that's already been logged once today flags it — "Already logged once today" — instead of quietly logging a second copy. That catches an accidental repeat in the moment, rather than leaving it to be spotted later in the finished minutes.
  • Typing a number the book's own index has no song at all — a mistyped page, or a genuinely blank one — isn't accepted quietly either. A second tap of Done ("Add anyway") logs it, so a typo doesn't slip into the record unnoticed.
  • A few books number some pages outside the ordinary page-plus-top/bottom pattern — roman numerals in the front matter, a lettered appendix, or two different songs sharing one printed number. Any book like that shows an OTHER badge next to its name; tapping it turns the keypad into a plain numbered list of those real pages instead, so they're just as loggable as an ordinary page and always recorded exactly as printed.
  • Tap Break to mark a recess.
Simple Minutes never asks who led a song — that's the entire point of it. When the finished log opens in Simple Compile or the full Minutes app, that absence is detected automatically, and the minutes come out reading as prose about what was sung, rather than repeating "the leader" once per song. Nothing has to be set on either side for that to happen.

Correcting a Mistake

Tap any already-logged song in the list to edit it in place. The same page checks — top/bottom prompts, the already-logged flag, the confirm-to-add step for an unrecognized page — apply to an edit exactly as they do to a new entry.

For anything about the singing itself — event name, date, location, number present, which books are selected, or break times — tap Edit setup. It's available the whole time you're logging, not just before the first song, and going back into it never disturbs anything already logged.

Finishing Up

  • Download CSV saves the file to the phone's own Downloads (or equivalent) folder.
  • Copy CSV puts the same content on the clipboard, ready to paste into an email or message.
  • Either one is a genuine, complete Schema 5 Singing Record — the same format the full Minutes app produces.
A Simple Minutes CSV isn't meant to be read on its own — it's page numbers and timestamps, not finished minutes. The real last step is opening that file in Simple Compile or the full Minutes app, either of which turns it into an actual narrative write-up (or the SHMHA Minutes Book format, or a terse scan list) ready to send to the rest of the class. Simple Compile is the quicker of the two for this — open the file, pick an output, copy or share the result — since it has nothing to fix up first; use the full Minutes app instead if something in the file genuinely needs correcting.

Saving and Backups

  • The log saves to this browser automatically as you go — no action needed, and no separate "save" button to remember.
  • Refreshing or closing the tab by accident and reopening on the same phone and browser restores exactly where you left off — the event details, the book, and everything logged so far.
  • Local saving isn't a substitute for a real backup — download or copy the file once the singing ends, and don't close the tab until you've done one or the other.

Where the Songbook Data Comes From

On opening, Simple Minutes first tries fetching the current tunebook list from the Tunebook Registry, so it has the latest book list whenever a connection is available. If that fails — no signal at the venue, a blocked connection, or simply the very first time this tool is ever opened — it falls back immediately to the copy bundled right beside the app itself, with no prompt or picker in the way. Either way, that file is only ever read as data, never run as code.

Everything Stays on the Phone

No singing data is ever sent anywhere. The log lives in this browser until you download or copy it yourself; the only network request Simple Minutes ever makes is the one read-only fetch of the current tunebook list, described above.

Troubleshooting

A page I typed shows the wrong song, or no song at all

Double-check the book selected at setup — song numbering is specific to the edition, and two editions of a similarly-named book can number the same page differently. If the book genuinely has no song at that page, "Add anyway" logs it as typed rather than blocking it outright.

I can't find a book in the list

Use the search field rather than scrolling — most books Simple Minutes knows about are reachable only by searching, since any one singing only needs a couple of them visible at once. If it's genuinely missing altogether, write to sacredharpbiblio@gmail.com.

The clock isn't warning me about a break

Check that an expected break time was actually entered — tap Edit setup to add or fix one at any point, even mid-singing. The warning starts five minutes early and clears two minutes after the time entered.

My phone went to sleep and I lost my place

Nothing is lost — the log autosaves continuously, so reopening the tab restores it exactly. Turning on "keep the screen awake" at setup prevents the phone from sleeping in the first place.

I need to fix a name, or this needs real editing

Simple Minutes doesn't record names at all, and has no editing beyond correcting a page number in place. Open the exported file in the full Minutes app for anything beyond that.
